# 🏡 Airbnb Clone – Backend Project

A full-stack Airbnb Clone built using **Node.js, Express.js, EJS, and Tailwind CSS**. The project demonstrates backend development concepts, modular routing, dynamic page rendering, and database management.


## 🚀 Project Overview

This project replicates the core functionality of an Airbnb-style rental platform. It focuses on building a structured backend with organized routes, server-side rendering, form handling, and data management.


## 🛠️ Tech Stack & Tools

- **Backend:** Node.js, Express.js
- **Template Engine:** EJS
- **Styling:** Tailwind CSS
- **Database:** MySQL
- **Data Storage:** JSON
- **Development Tools:** Nodemon, npm, Git, GitHub


## ✨ Key Features & Concepts

- **Modular Routing:** Organized route handling using `Express.Router`.
- **MVC Architecture:** Separation of routes, controllers, models, and views.
- **Dynamic Rendering:** Renders dynamic web pages using EJS templates.
- **Form Handling:** Processes form submissions using `express.urlencoded` middleware.
- **Property Listings:** Displays property details, including names, prices, locations, ratings, and images.
- **Favourite Homes:** Implements functionality to manage favourite properties.
- **Database Management:** Uses MySQL for database operations and JSON files for data storage where applicable.

## ⚙️ How to Run Locally

### 1. Clone the Repository

git clone https://github.com/salonisingh66/airbnb-project.git


### 2. Navigate to the Project Directory


cd airbnb-project


### 3. Install Dependencies


npm install


### 4. Configure the Database

Set up the MySQL database and configure the connection details according to your project settings.

### 5. Start the Application

Run the appropriate start command defined in `package.json`, or start the server using Node.js.

### 6. Open in Browser

Visit the local URL displayed in your terminal to explore the application.
